# 验收与验证

## 本地功能验证

`sh scripts/test.sh` 运行标准库 unittest 核心与真实 HTTP 测试，使用临时数据库，不写入演示工作数据。

覆盖：

- 无会话访问、错误口令、跨站请求与未授权写入。
- 六岗位资料范围、目录与直接卷页接口的权限边界。
- 创建、公开试点权限核验、整理员确认接手、引用、提交、审核员接手、审核、交付。
- 无引用不能提交，未审核不能交付，接手前不能推进。
- 过时版本、歧义资料、错误页码、错误映射、更正未确认、重复引用与资料版本变化拦截。
- 退回需原因；保留退回记录、清空旧引用并重新定位。
- 异常分派、实际岗位处理、审核复核、整理员接手恢复，原档案不被覆盖。
- 暂停后正常推进停止，人工异常与草稿可继续；恢复权限限保护专员。
- 陈旧修订号不覆盖最新草稿；重启后持久化保留，重复初始化不重复植入样例。
- 审计禁止应用更新与删除；反馈受理与审核核对分离。

## 真实试点尚待完成

报告的 50 分钟/6% 为访谈锚点，不能当实测基线。引用准确率 99%、受限泄露为零为验收目标，本地测试通过不等于该目标已通过。

试点前明确：公开高频卷类别、历史回放区间、合格样本数、每笔业务分母、排除与修复记录、准确引用判定、抽样复核人、六节点起止时刻、P90 阈值、停止条件清单、转人工时限、复核人和升级路径。

实测输出须包含：样本来源与数量、排除原因、规则与资料版本、准确及错误引用计数、越权专项测试结果、各节点等待和处理时长、错卷计数、人工复核成本、端到端交付时长和未解决问题。

先历史回放，指标复测后再小范围并行试点。触及约定停止条件时暂停，保护专员与业务负责人复盘后决定恢复或退回整改。
