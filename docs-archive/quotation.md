## 一、报价方案与适用范围

本方案面向已有数字档案目录和扫描件的单位，建设“申请 → 权限核验 → 检索 → 卷页核对 → 审核 → 交付”的小范围协同试点，保留异常分派、人工复核和过程追溯。

现有仓库是合成数据功能演示，尚未具备真实档案、真实 OCR/AI、生产统一身份及真实同步能力。本次报价将其中必要能力列入建设工作，价格对应下表约定的范围。

| 范围项 | 本次包含上限或约定 |
| --- | --- |
| 组织与场景 | 1 家单位、1 个试点部门、1 类公开档案、1 套查阅业务主流程 |
| 用户与岗位 | 不超过 30 个具名账号；按现有六类岗位配置，含用户与岗位对应关系 |
| 运行规模 | 以 10 个并发活跃用户作为首期验证目标；不属于高可用集群建设 |
| 部署环境 | 客户提供的 1 套测试环境、1 套试点运行环境；采用双方确认的单节点应用部署方案 |
| 档案数据源 | 1 套原档案系统，使用客户提供的已授权、可调用的只读接口；包含目录、版本、更正关系、卷页读取和授权查询所需字段映射 |
| 身份接入 | 对接 1 个现成 OIDC 身份提供方；不含建设身份平台或适配专有认证协议 |
| 数据规模 | 首批不超过 10,000 条目录、50,000 页已数字化卷页；含 1 次试导入、1 次正式初始化及结果核对 |
| 数据整理 | 包含字段映射、格式检查、异常清单；最多人工核对 500 页映射样本，不含全量逐页清洗 |
| 业务验证 | 不超过 200 笔历史业务或验收任务；客户提供样本与独立复核人员，包含 1 轮初验和 1 轮整改复验 |
| 现场及培训 | 远程交付为主；包含 2 场远程培训，每场不超过 2 小时 |
| 数据边界 | 仅处理客户确认可用于本试点的公开档案；不包含涉密档案业务 |

如果原系统无法提供稳定接口、授权结果、可核对版本或卷页地址，应先调整范围与费用，再开展真实接入。

## 四、验收内容与边界

正式合同应附确认后的测试用例、样本清单与判定标准。本报价建议采用以下交付验收内容：

1. **业务闭环：** 约定范围内的申请、权限核验、定位、引用、交接确认、审核、交付与反馈可执行，状态、责任及事件记录一致。
2. **引用核对：** 对客户确认的有效样本，能够核对档案标识、资料版本、扫描页与纸质页；已知错误、过期版本和缺少必要映射的资料须提示或拦截，不能静默计为成功。
3. **权限与故障：** 按确认的用例验证越权访问、授权撤销、上游不可用、过期快照等场景；出现未解决的约定阻断缺陷不得验收进入试点使用。
4. **运行与恢复：** 在客户确认的环境及数据规模下验证 10 个并发活跃用户的核心流程；响应时间阈值在实施设计阶段根据环境写入验收附件。完成一次备份恢复演练。
5. **可追溯性：** 可根据业务号追溯所用版本、卷页、核对人、接手、审核及交付事件，并导出约定记录与审计校验结果。
6. **交付完整性：** 提供约定源码、配置模板、操作与运维文档、测试及试点评估报告，完成培训；源码和配置包不含账号口令、客户档案或运行会话。

定位时间、引用准确率、错卷率和端到端时长应在试点中测量。现有材料中的“平均定位 15 分钟、错卷率 1%、引用页码准确率 99%”尚未在真实业务验证，**本参考报价不承诺这些效果已达标**。如客户要求将业务效果作为付款条件，需先确认基线、样本、数据质量、统计方法与责任，再更新报价及验收附件。

审计交付为应用留痕、独立导出及完整性检查，不包含专用防篡改存储采购或第三方认证，也不宣称绝对不可篡改。
