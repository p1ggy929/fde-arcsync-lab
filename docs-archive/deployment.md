# 运行、打包与接入

## 本地运行

macOS 双击根目录 `启动项目.command`，或执行 `sh scripts/start.sh`。脚本检查 Python 3.11+、自动创建 `.venv`、按需安装 requirements.txt，然后等待服务就绪并打开浏览器，默认 127.0.0.1:8765。缺少依赖时需要联网。可通过 `ARCSYNC_PYTHON` 指定用于初始化环境的 Python 解释器。

请保留启动窗口，使用 Ctrl+C 停止；已保存的 SQLite 数据保留，数据库被 Git 与构建包排除。重复启动会打开现有 ArcSync，不创建第二个服务；其他程序占用端口时提示更换。已有服务沿用其启动时的环境配置，如需切换数据库，应先停止服务再重新启动。

可选参数：`--check` 仅准备环境；`--no-browser` 不自动打开浏览器；`--port 8877` 或 `PORT=8877` 更改端口。

## 打包

`sh scripts/build.sh` 进行语法校验并生成 dist/arcsync-0.3.0.zip。解压后按 README 运行，首次启动生成独立合成数据与演示账号。代码包不含运行时数据库或会话。

## 真实系统接入前置

1. 秦芮确认档案库、OCR、授权审核台的读写清单、身份映射、主编号、资料版本和权威字段。
2. 唐映秋与傅景确认可自动/须人工清单、开放授权、规则版本、异常接手人和处理时限。
3. 顾明岚确认试点卷类、样本、预算分项与统计口径；合成访谈不能替代真实业务确认。
4. 实现符合 integrations/base.py 契约的只读适配器；索引构建、查询、卷页读取、缓存与模型上下文均遵守授权。
5. 加入授权撤销同步、快照时效与故障时失效关闭；实现按业务编号和事件版本去重补齐与检查点。
6. 需要模型时先确定本地/获准部署及数据边界，再实现有依据引用的检索辅助；模型不调用开放、处置与源系统写入操作。
7. 生产使用 Uvicorn ASGI 服务并配置受控进程管理，接入 HTTPS、SSO、具名权限、限流、受控配置、监控、备份恢复与访问审计；演示口令不能用于生产。
8. 实现留存期审批与到期复核任务，不能将报告中的临时 90 天直接当真实期限。
9. 用金标准历史样本和越权用例专项验证，通过后进行并行试点，不直接替换原流程。

本仓库不含云账户、部署凭据，也未向任何外部服务上传档案或代码。`scripts/deploy.sh` 给出本地运行和后续接入说明，不执行公网发布。

## 第三、四层部署

配置 `.env` 选择 Ollama、vLLM 或云端模型。MySQL 为可选业务库；本地容器模板与 SQLite 到空 MySQL 的迁移工具均已提供，详见 [模型与数据接入](model-setup.md)。配置变更需停止原服务后重新启动。未配置模型时不执行推理，原业务仍可运行。
