# 业务现状｜流程图简短说明

本图采用岗位泳道形式，展示云州档案服务中心“查阅申请—权限核验—档案检索—卷内定位—审核交接—资料交付”的主链路，并补充异常返工和反馈复盘路径。五条泳道分别对应查阅服务、档案整理、审核协同、数据系统、保护管理。蓝框为正常步骤，菱形为判断点，粉色虚框为断点或异常；fXX 标签对应需求发现报告中的证据编号。

**主要问题集中在找到材料之后的依据核对。** 目录标题相近，需要反复翻卷；更正文件未关联原卷，可能返回过时版本；OCR 日期错读、扫描页与纸质页码不一致，会增加校核和返工。关键说明散落在便签或群聊中，又使交接时需要重新补充上下文。

**最耗时的首要候选是“卷内定位与引用核对”。** 访谈称其约占 40% 工时，并提到有效材料定位平均约 50 分钟、日常约 130 次查阅。但各节点尚未分别计时，50 分钟的起止口径与分母也未核实，因此不能把它直接认定为某一步的实测耗时，更不能用 130×50 推算每日总工时。

**最耗钱的环节尚无核算结论。** 优先核算候选为“重复翻卷＋版本、页码异常导致的跨岗返工”，主要消耗整理员、审核员和工程师的人工投入；这是基于痛点的成本推断，不是已证实的金额排名。报告中的 20 万元是首期建设预算，不能当作现状运营成本或预期节省额。

下一步应按同一业务编号采集六个主节点的处理时间、等待时间、返工次数及参与岗位，再结合各岗综合人时单价核算成本。等待时长单独报告，不直接等同于实际人工工作量；节省工时也不直接等同于现金收益。

本图用于说明**改善前的业务问题与报告约束**。人工修复、复核及每周复盘等路径包含报告提出的处理要求，实际执行情况、责任细分和时限仍需核实；不代表这些机制在原业务中均已完整落地。资料来自合成场景访谈，须由真实日志、台账和现场观察交叉验证。
