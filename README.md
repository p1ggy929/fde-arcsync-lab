# 云州档案 · ArcSync

一个可本地运行的档案检索与查阅协同平台。围绕「申请 → 权限核验 → 检索 → 卷页核对 → 审核 → 交付」提供完整的演示流程，基于本仓库 `discovery-report.md` 建设。

**当前版本：合成数据功能演示，不含真实档案、真实 OCR 或 AI。** 原始需求来自合成访谈，真实接入、授权与验收口径仍需业务确认。

## 快速运行

环境：Python 3.11+；直接启动不需要 Node，也不需要安装 Python 第三方依赖。

```sh
sh scripts/start.sh
```

浏览器打开 **http://127.0.0.1:8765**。默认以档案整理员登录，演示口令为 **`ArcSync2026!`**。

前端不依赖外部字体、图片或 CDN。数据持久化在 `data/arcsync.sqlite3`，重启后保留。

可选：已安装 Node 时，`npm start` 启动，`npm test` 验证，`npm run build` 打包；无需 `npm install`。

自定义端口：

```sh
PORT=8877 sh scripts/start.sh
```

首次初始化时可通过 `ARCSYNC_DEMO_PASSWORD` 指定演示口令。该环境变量只影响新建账号，不能修改已有数据库内账号。用 `ARCSYNC_DB` 指定另一份数据库可创建独立演示环境。

## 已实现

- 工作台：责任待办、待接手交接、异常提醒、连接及快照状态。
- 查阅业务：创建申请、公开试点权限核验、业务台账、随单草稿与事件时间线。
- 档案检索：按关键词、类别、年度、状态查询授权目录，查看资料版本与更正关系。
- 卷页核对：合成卷页阅读器、扫描页与纸质页映射、人工确认引用、资料版本绑定。
- 审核交付：确认接手、提交审核、审核通过或说明原因退回、记录人工交付、导出文本记录。
- 异常处理：暂停建议、审核员分派、实际岗位填写处理结果、审核复核恢复。
- 服务反馈：关联业务与资料版本登记，由审核员核对。
- 管理审计：六岗位服务端鉴权、审计追加记录、试点暂停、保护专员复盘恢复。
- 试点评估：真实数据库中的流程计数和原始事件；不伪造定位提速、准确率或零泄露结论。

## 走通一笔业务

1. 以 **林亦舟 / 档案整理员** 登录；打开「档案检索」。
2. 检索「总体规划」，打开有效资料或后续更正文件。过时与待修复资料不能直接加入依据。
3. 打开卷页，核对页码；选择「县城总体规划批复查阅」，勾选人工确认后加入业务依据。有后续更正时还须确认更正核对。
4. 在「查阅业务」打开该业务，填写随单说明，点击「提交审核」，填写交接说明。
5. 右上角切换为 **唐映秋 / 查阅审核员**；在「审核与交接」确认接手。
6. 打开业务，填写审核依据并通过，再记录人工交付，可导出带引用信息的合成交付记录。
7. 另一条路径：发现页码或版本问题时转人工；审核员分派，切换实际处理岗位填写结果，再由审核员确认接手并复核恢复。

新建申请从「待权限核验」开始：审核员核验公开试点范围后，整理员须先确认接手才能定位。退回与异常跨岗恢复也须确认接手。

## 六个演示岗位

| 岗位 | 姓名 | 主要能力 |
| --- | --- | --- |
| 档案整理员 | 林亦舟 | 检索、核对引用、提交审核 |
| 查阅审核员 | 唐映秋 | 试点权限核验、审核、异常分派与复核、交付 |
| 档案保护专员 | 傅景 | 专员范围资料、审计、暂停与复盘恢复 |
| 档案系统工程师 | 秦芮 | 数据异常处理、本地快照刷新 |
| 档案服务主任 | 顾明岚 | 管理状态、脱敏审计、暂停试点 |
| 业务查询代表 | 叶书 | 申请查阅、受理反馈、查看进度 |

岗位切换用于本地验证，不是生产身份管理。只有保护专员可看到受限测试资料；该资料不得关联到公开试点业务，主任权限不自动扩大档案访问范围。

## 验证与交付

```sh
sh scripts/test.sh
sh scripts/build.sh
```

测试覆盖完整流程、跨岗接手、越权读取与写入、页码与版本拦截、暂停、冲突编辑、异常复核、反馈和数据库持久化。HTTP 测试需要允许绑定本地临时端口。

交付包位于 `dist/arcsync-0.1.0.zip`，不含数据库、会话和环境口令。CI 运行同样的验证与构建。

## 项目结构

```text
src/frontend/             中文界面、样式与交互（无构建依赖）
src/arcsync/main.py       本地 HTTP 入口、会话与接口
src/arcsync/core/         数据、权限、状态流转与审计
src/arcsync/integrations/ 外部系统接入契约（未启用）
docs/                    设计、接口、验收与部署说明
tests/                   核心规则与真实 HTTP 回归测试
examples/                可运行的接口示例
scripts/                 启动、验证与交付打包
config/                  非机密配置模板
data/                    运行时本地数据库与样例说明
.github/                 CI、问题模板与 PR 模板
```

## 当前边界

本地服务只监听 `127.0.0.1`。档案库、OCR、授权审核台、AI 和真实 SSO 尚未接入；关键词检索使用目录与固定摘要，卷页由合成模板生成。没有对原系统回写或档案删除接口。

暂未实现真实定时同步、断线重连补齐、生产级不可篡改审计、留存到期审批任务、SLA 自动升级、金标准标注与实测准确率计算。界面对此均不宣称已完成；后续见 [部署说明](docs/deployment.md)。

需求来源及限制见 [发现报告](discovery-report.md)，详细实现见 [设计说明](docs/design.md)、[接口文档](docs/api.md)、[验收说明](docs/acceptance.md)。
