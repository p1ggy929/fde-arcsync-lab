# 云州档案 MVP

本机运行的公开档案查阅工作台。包含关键词检索、合成卷页阅读、人工引用核对、岗位交接、申请审核和人工交付记录。界面由服务端渲染，启动只需要主项目的 Python 环境。

## 启动

在仓库根目录执行：

```sh
PYTHONPATH=src .venv/bin/python -m mvp
```

如尚未准备 `.venv`，先执行 `sh scripts/start.sh --check`。打开 [本机 MVP](http://127.0.0.1:8766/)。需要更换端口时，在启动命令后添加 `--port 8876`。用 `Ctrl+C` 停止服务。

数据库保存在 `data/mvp/arcsync.sqlite3`，首次启动自动初始化演示记录，重启后保留。会话与主项目使用不同的 Cookie。三个演示岗位的密码均为 `ArcSync2026!`。

## 演示一笔业务

1. 以业务查询代表叶书登录，在「查阅申请」新建一笔申请，记下标题。
2. 从页首「切换岗位」登录查阅审核员唐映秋，打开刚创建的申请，确认公开档案试点范围并交给整理员。
3. 切换到档案整理员林亦舟，在「查阅申请」确认接手。在「档案检索」搜索「总体规划」，打开「关于县城总体规划局部调整的通知」，核对扫描页和纸质页码，再选择该申请并加入依据。
4. 返回申请，填写交接说明并提交审核。切换到唐映秋，确认接手，填写审核意见并通过审核。最后填写交付说明并记录人工交付。
5. 切换回叶书，打开原申请确认状态为「已交付」，并检查依据和流转记录。

审核员也可填写理由退回整理。退回后整理员需重新确认接手并核对依据。

`__main__.py` 是启动入口，`app.py` 接入现有鉴权和业务规则，`views.py` 渲染页面。演示使用合成档案和人工流程，无需配置模型服务。应用仅监听回环地址，供本机演示。
